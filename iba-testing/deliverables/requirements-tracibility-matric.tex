\section{Introduction}
The Requirements Traceability Matrix (RTM) is a sub-deliverable of the Test Plan for the IBA Campus Facility Booking System. Its purpose is to ensure that all functional requirements defined in the Software Requirements Specification (SRS) are mapped to specific test cases. This ensures 100\% test coverage and validates that every system feature is verified during the testing lifecycle.
